# 萌饲Zoo

萌饲Zoo 是动物园数字陪伴与到园转化平台的可运行前端原型。它把“领养动物—每日互动—科普任务—领取权益—到园打卡—生成回忆”串成一条完整体验。

## 已实现

- 3 位动物朋友：东北虎“小满”、小熊猫“团团”、绵羊“绵绵”
- 动物领养与切换，本地保存领养进度
- 喂食、梳毛、玩耍三种照顾互动
- 每日任务与 3 道科普问答题
- 园内三点位地图与模拟打卡
- 陪伴值兑换真实园方权益，生成兑换码
- 成长回忆册与月度陪伴统计
- 园方运营看板、转化漏斗、核销台和内容审校
- 儿童模式开关，适配桌面和手机

## 运行

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。

生产构建：

```powershell
npm run build
npm run preview
```

## 技术栈

- React 19
- TypeScript
- Vite
- Lucide React

## 数据说明

当前版本是校赛演示原型。领养、任务、权益和看板数据保存在浏览器 `localStorage`，看板中的转化数据均为演示数据，不代表真实经营结果。正式上线前需要接入园方账号、内容审核、兑换码核销、隐私政策和儿童信息保护流程。
